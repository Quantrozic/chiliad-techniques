OK so i know there is lot's of information about this aspect of the mural but it's scattered around this sub and is often overlooked. All i ask is that we get as much lightning info in this one thread to make things more streamlined and develop grounded ideas.

there are various missions in the storyline that induce lightning. two i can think of are friends reunited and the one where trevor flies to north yankton. i'm sure there are others but i can't recall so mention any you know of here. it would be handy if there happened to be "no not like ten, exactly ten" for obvious reasons.

there is also the weather cycle that was pulled from the files a while back which showed only 3 instances of thunder, 1, 2 and 3 time units in length respectively, so if we could get some records of times and days of these and check if they match up it may help greatly.

thanks in advance for your help and ideas.
