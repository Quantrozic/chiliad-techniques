Eastern Motel morse code

▲ 4 ptsu/TrevorsbuzzardOct 18, 201619 comments at captureOpen original on Reddit ↗
Documented under:Atbash Substitution TestingFrequency Analysis Substitution CrackingFrequency-Analysis Substitution CrackingIconographic Color-Code AnalysisMorse Code Analysis

The motel in Harmony in the Senora desert has a big neon sign. If you listen it makes a neon buzzing noise that sounded like morse code to me. So I used a morse code reader on my phone to see if it was anything. It only makes the noise at night time and my app recognises it as morse code, but there is such a lot of background noise it's hard to make out.
Here is what I got;
"OENSIGN TT T T N TT E OT T ISEEIIE SEG ERE61 MSEII ERE TIT MEEIT GA I T CUTEMEN TISU DNT GIEEEEA NO OT CHEET DEEEE+AWN UEI HPEHIE R S I H NE 6E KEN GE GFMHMALIS"
It makes no sense but then I am using a free app without clearing it up, but the fact that it is reading as letters and numbers is interesting.
If anyone has any better equipment, might be worth a look?
