I've noticed that a lot of posts are getting jumbled up, and it might not be overtly clear what some posts are trying to accomplish. It might be better if we start tagging posts using a predetermined list.

[Speculation] - for when you have an idea, but don't know if it's right yet. This can help people work together to solve specific parts of the puzzle. This will involve pieces of the puzzle that everyone already knows about.

[Discovery] - What's that? You just found a never-before seen glyph/UFO/event? Great! Make sure everyone knows that you have uncovered something completely new by tagging it accordingly!

[Discussion] - If you don't have a particularly new theory about the puzzle, but want to discuss/brainstorm ideas, then start a discussion. This way, people know that nothing is off the table.

[Meta] - Discuss this subreddit, and what goes on within it, like this post is doing.

This could also help the mods sort out every comfortable piece of evidence discovered so far, and add it to the cumulative list in the sidebar. A little organization never hurt anyone.

And if you have any more ideas for tags, let me know!
