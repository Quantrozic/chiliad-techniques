When I decided to start looking at files for GTA V, this texture was my white whale.

I am proud to present the original texture, (converted from DDS) as well as one I enlarged by 2X to help with viewing.

I will continue to search to see if there is a higher resolution texture, but at the moment, I doubt there will be one.

This file can be found using OpenIV in the directory C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto V\x64j.rpf\levels\gta5\_citye\hollywood_01\hw1_15.rpf\

NOTES - I took the original texture, blew it up by 500% and sharpened it up a bit in Gimp 2.
