So I've been doing a lot of testing with how the game requires internet access, and the involvement of the Social Club profile.

Why does rockstar require us to be online for a SINGLEPLAYER game. This is because we upload our progress to our Social Club profile. I've been doing some testing with this, the info that's displayed, and what triggers an update.

I started with doing some packet capturing on Wireshark, noticed that every time you save, it sends leader board information to social club. I'm curious to know if the codewalkers have seen this in the code, and if so, what type of things can trigger the "send" function besides saving. At some point, i'm going to be testing wireshark on a bluestacks instance with the GTAV app installed. I'm curious to see if i can see any "clews" in the data sent from the app to SC, especially with the Chop integration.

Another thing I've noticed: On fresh files, when you take the cable car up, as soon as you step out of the car, you auto save. but only on the first time. I tried to get it to auto save again, even tried triggering a save following that autosave, but it would not trigger an autosave. I ended up reloading the file to a previous point, and it did auto save. Edit: This is an objective under the "Misc" category, this is why it triggers an autosave. still something to note, imo.

Also, you can manually update your profile by doing a manual save by mission or sleeping in bed. haven't done too much testing with quick saving via the phone.

I'm still doing testing with this, realized that i can't do the stock car races on my current 100% file, so i need to start anew.

My plan:

  • Follow R\*'s checklist according to my social club profile.
  • Wait to give Omega spaceship parts
  • save before the final mission (Choice A, B, or C)
  • Perform all random events except for events where Trevor can make a sacrifice.
  • No epsilon missions performed
  • No Children of the Mountain Objectives performed.
  • All Stats 100%
  • Fill other stats Social club tracks with at least some data (no zeros)
  • Do NOT use the cable car to go up Mount Chiliad

With this, I hope to create a decent save file to test with. From what I can see, using standard scripthook mods with a basic trainer does not stop the game from sending data to our SC account.

Another thing I'm keeping an eye on as I play is the "Overview" tab on the desktop browser version. Seems to be some interesting images that show up on the board, I'm curious to see if it changes throughout the story.

I'll be updating when I gather more information, unfortunately i'm only able to play outside of work for 2-3 hrs a day, but i'm devoting all I can. A lot of this jumbles into the base ideas that a) this can be "solved" on X360/PS3, b) Karma/play through theory (certain things need to be completed by 100%/ possibly "The Third Way" having different dialogue ? \[ the ending dialogue seemed pretty awkward, like "yeah, gg guys, cya", especially Trevor.\])
