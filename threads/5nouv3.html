S.O.S. morse code at Rebel Radio and the Altruist Camp.

I made a quick video showing something I discovered, I can't say for a fact it's not a glitch, but I decided to share it anyway.

You know the altruist message morse code you can hear at the Rebel Radio Tower at 3:00 am? (The same message that appears on their website), we know creating an explosion near the radio tower changes the message to S.O.S.... well, it seems it has some kind of effect at the Altruist Camp, whenever the S.O.S. message goes off, the altruists start freaking out, some of them were even yelling "they found me!" and "this is the end!" and jumping off the cliff!!!

I've been able to replicate this several times, however, I noticed It only seems to work if there's the original altruist message going on first, and THEN you interrupt it with the S.O.S. morse code.

Anyway, sorry for the short video, the free version of fraps only allows me to record up to 30 seconds.

In the video I provided, you can hear it starts off with the long Altruist message first (the one about the industrial revolution, etc) and then it changes to the S.O.S.

So maybe it makes sense for the Altruists to be receiving messages from the Radio Rebel Tower, as they're connected in several ways in the game (the morse code, the skull logo, etc), it might be possible that the S.O.S. signal makes them freak out for some reason....

I thought that maybe this is related to the Oeuvre painting with the radio tower with the "Gush Gush Gusher", but im not sure about that.

I don't know if this is anything, but I thought i'd share it.

Happy Hunting! :)
