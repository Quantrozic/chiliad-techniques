First GTA Death Screen - Followup theory regarding file naming for the animation

Documented under:Filename & Asset Metadata ArchaeologyOptical Flow Glyph Motion

So, like much of the jetpack hunt thus far, this will probably won’t amount to anything, however its beyond my ability to test/investigate this, so I thought I’d put my thoughts out to the sub.
So the discussion about the Episilon chap that floats around in front of you when you die for the first time on GTA:O raised some questions in my mind that MIGHT be worth following up.

The key points to debunking the lack of importance in this cinematic were:

-If he's wearing a jetpack, where are the straps/exhaust

-Even if he was wearing a jetpack, its not as if you can interact with the cinematic in anyway, and therefore is not worth mentioning

If it were possible to look at the names of the motion capture animation files themselves for that cinematic, then it might shed some light on why this 3d model moves like it does, when from my recollection nothing else, In any cinematic in the game, or general game animation, moves quite like it. Ultimately you can’t deny that his body behaves in a way that a 'modern day’ San Andreas jetpack might be animated/mocapped to behave. Another observation was that you can hear a faint 'engine/exhaust' noise in the background.

All this makes me think what if this cinematic was quickly 'thrown together' for GTA:O in the sense that when you think about what the cinematic really is, it’s just a 3D camera pointing at a 3D model floating in midair POSSIBLY wearing an unrendered jetpack for a ‘hover’ effect and a simple blue sky background, and that’s it, very ‘simply’ done in other words. No other 3D model animation in the game looks like this, and while it is a 'cinematic', all the cinematic's took place inside the game engine as far as I knew.

TL;DR - GTA:O first death animation has a likeness to a jetpack animation - if the name of the animation could be found (without significant hassle), it might give more credibility to the actual existence of jetpack mechanics already existing in the game.
