Choice of Ending

Had a random thought. We all pretty much assume that option C in which all characters survive is the canonical ending. And also that any hidden item would be unlocked using this ending. What if that's wrong and its another ending (or alternate universe) that triggers an event?

This will probably sound a bit out there (although considering some theories maybe not) but what if Michael or Trevor's corpse gets taken by the aliens and that becomes a miniature storyline all by itself.

It would obviously need to be unlocked in some way as nobody has discovered it so far but given most theories and investigations have been carried out on one ending it seems like two other avenues have been ignored entirely.

This is all complete conjecture on my part and I haven't quite finished the game yet but I think I'll take the ending in which Michael dies. When he's drugged he either gets abducted or imagines he does, and during the first FBI mission he ends up in a bodybag in the morgue. He's even had his death faked before. Foreshadowing?
