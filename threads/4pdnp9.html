I was having some trouble finding the dead hunter, after eating all 7 peyote's, so I decided to make a guide for everyone. Here's how to get to the dead hunter most efficiently to start exploring!

First of all, here's what I used

MAP OF 7 PEYOTES

Native trainer

Menyoo

100% save

Now that we have all we need, lets get started!
First of all load up that 100% file. It contains all of the previous things you need to start collecting those peyote's.

Next up open up Menyoo via the F8 key and go down to time settings. Make sure your time is set to 6-8 on a Sunday (To check your date, simply open up your phone via the up arrow)

Now we can head to the first Peyote, looking at the map you can set a way point and teleport there. I press F4 on the native trainer, and select player, teleport to way point. They can be hard to find, so I tried to make them as easy as possible.

Just remember, after finding one peyote, use menyoo to change the time ahead by 24 hours, then check your phone again to confirm the change.

Hope this helps you all and happy hunting!
