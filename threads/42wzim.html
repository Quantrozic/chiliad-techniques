Im new here, did some reading so ignore this if a lot of this has already been done.

A lot of games hide easter eggs in sounds, which can be discovered with spectral analysis. This would mostly be interesting for sounds like computers beeping or scribbling noises like hard drives make. I know some analysis has already been done, but I feel like without doing more of this we only really analyze what we see, and not what we hear which kind of leaves half of the potential info in the dark. Maybe somebody can go back and check some sounds related to the FIB, around the satelite dishes when the FIB agents show up there, black cellphone stuff and pretty much any points that seem like dead ends with something more to them.

Just a thought I had...

Edit: A lot of people here seem to like this idea, so how about we talk about what places could have interesting messages. If u have a interesting idea, put it in the comments and we can decide on whether or not its interesting.

I suppose logically these sounds wouldnt be hidden reeaaally randomly. They would be hidden in:
A) Special sounds directly connected to the FIB, ufos, mural related stuff, satelites, SD horn noises etc.

B) Random sounds like beeping and buzzing with no "real" purpose

C) Sounds that people working at rockstar had to put special effort into, with advanced planning etc. Which makes it more likely for some guy there adding secret stuff into it ;)
