Underwater hatch lights

▲ 25 ptsu/Natural-PutJan 8, 20264 comments at captureOpen original on Reddit ↗
Documented under:Morse Code Analysis ?

While I was examining the underwater hatch, I noticed that the lights occasionally turn off. I checked the game files, and it turns out the developers programmed specific times for the window light to be deactivated. I haven't seen anyone mention this before, so I’m sharing it now in case someone can provide an explanation as to why this might have been important for the developers.
I also examined the audio file; there is only one rule applied to it: it can be heard at any time of day, but it only triggers once every 5 hours.
