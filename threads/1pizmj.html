Possible Morse Code Message On Building Lights Near Studio

Documented under:DTMF and Morse Tone DecodingMorse Code AnalysisMorse-on-Envelope Detection

Not my pic, so kudos to KILGGR: this building may have a coded message, possibly Morse code in the colored lights surrounding the whole building.

There are three rows of lights.

The light fixtures appear either singularly or in small groups no larger than 4.

They either face left or right.

It is also possible that the color is somehow the key or a modifier to decryption if it is indeed a message. The colors are cyan, yellow, green, purple, and red. These are also the same colors used on the Altruist's website's message, which is also in Morse code. Remember that the Altruist connection may just be a coincidence though. Those colors appear other places in the game world in different orders. The only specific examples I can think of are in some 2nd floor windows near the large horse statue, and pillars at the LS airport.

I need to get over there to grab some closer pictures, but I've already shut the set down for the evening and only noticed this while sleepily looking through snapmatic for clues. If no one beats me to it, I will attempt a complete investigation in the morning.

EDIT 3:Definitely not a simple Morse code based on any variables I can see. I've tried using left facing lights as . (dits), and right facing as - (dahs), and vice-verse. Ended up with junk, and difficulty in several places.

The spacing is not quite uniform, and there are far too many single lights.

In Morse code the only letters described as single characters are E ( . ), and T ( - ), which is funny, but leads to a lot of garbled nonsense.

If uniform spacing is not a priority, then I gotta assume this is not Morse code. I'll spend a little more time looking for chunks that look decipherable, but I'm not optimistic.

Since the Morse thing didn't pan out I'm gonna go ahead and put the Debunked flair on this. I do have a couple other theories though, one involving a color wheel( inspired by the Ferris wheel on the pier cycling the colors). But really, its getting kinda advanced and - unless somebody at R* is reeeeaaaalllly into creating these crazy ambient visual puzzles - I'll likely move on from this location soon.
