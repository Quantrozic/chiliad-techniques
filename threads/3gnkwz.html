Why is everyone overlooking the eclipse?

▲ 5 ptsu/Breet4terAug 11, 201551 comments at captureOpen original on Reddit ↗
Documented under:Moon-Phase Condition Testing ?

There's proof of an eclipse in the game, that "coincidentally" takes the same shape as the glyph above the mountain on the map, and the glyph even seems to symbolize what an eclipse would be drawn as in its most primitive form... The eclipse was either entered into the game on purpose or is some kind of glitch... If it's a glitch, then you can disregard all of this, but it would've been corrected by now. If it was entered on purpose, there has to be some significance to it or else people would just see it and assume there's something fucked up in the game. Is it possible that some event needs to take place during the time when the eclipse shows itself? Is it possible to program something like that into the game? If it's an event that needs to be triggered within that ~10 second window that (predictably) occurs during a long cycle, then that could explain why there have been no real significant leads since the game released, because there is such a small window within which anything we do actually matters.
