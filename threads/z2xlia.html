? - how are the cutscenes stored within the game files?

▲ 23 ptsu/LocomuleNov 23, 202210 comments at captureOpen original on Reddit ↗
Documented under:Frame-Step Cutscene Forensics ?

It has only just occurred to me that I've never seen anyone mention datamining cutscenes. Is anyone familiar with their storage method within the game files or if anyone has successfully decoded them? Obviously there is a cut scene display system that relies on the game engine to portray them as opposed to stored video as elements within cutscenes such as player clothing can vary. So somewhere there are chunks of data dedicated to all the parameters and elements used to portray each scene.

I'm guessing this system has never been fully cracked by the data miners otherwise we'd have confirmation of never triggered cutscenes or that we've seen them all.

The reason I ask is because I've been reconstructing the Kyle P Slater dialogue into a mission sequence. Working on it lead me to consider that if it, or anything else undiscovered, involved a cutscene then obtaining and studying that cutscene data would seemingly big step towards figuring out how to unlock it. Every cutscene potentially involves characters, locations, dialogue, game objects, camera directions, environment variables, and a whole lot more. Considering the sheer amount of cutscenes their must be some pretty big lists somewhere?
