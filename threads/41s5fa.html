Are the UFOs available in director mode and if so does black cellphones disable the visual/screen EMP effects of the UFOS? Is Directors Mode?

Documented under:Director Mode Scene & Spawn Testing

Tl; dr: Can someone on current-gen please test if activating black cellphones disables the onscreen visual distortion of the UFOs in Directors Mode? Maybe the code is only for the film-makers?

My reasoning:
When you approach the Sandy Shores UFO you get a visual "EMP" effect that scrambles the screen - this prevents taking a decent photo (or video) if you happen to be very close. I believe that the UFOs are available in director mode therefore there is a reason to turn this off for film-making.

Directors mode uses the open-world map and presumably the same physics as the story so I presume the visual distortion of the UFOs is present also. Rockstar want to implement a method of turning this off for directors mode (if needed) but not effect it in story. In directors mode the only phone function available is Snapmatic. So you would have to activate it in story first (by dialling the number) and then switch to directors mode.

Obviously, there should be no reason for Rockstar to hide this feature but it's possible they are finding it difficult to work correctly and are still testing it (hence all the confusion).

Interesting, you cannot enter directors mode in a vehicle (like the explosion) but have to be outside - this is all conjecture on my part but I haven't seen anyone test this before. I don't have a system to test this myself but it would be a very simple thing to check and eliminate.
