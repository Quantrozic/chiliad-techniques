Does GTA V have a 'debug' mode? What does RAGE's console look like?

▲ 22 pts[deleted]Oct 15, 201621 comments at captureOpen original on Reddit ↗
Documented under:Shared-Engine Behavior Comparison

This might be really dumb, and quite off track, but hold on for a second and hear me out. Say you're writing a complex program and you want to make sure that one of your functions is actually being called. You could use print("function X ran successfully") or something to that extent to print out success to the console so you can see that your code is working right without showing the user anything.

Something has stuck with me: "By the way. You could if you were smart set up a program to analyze markers in the hex code of all binary files of the game and supporting files. Play the game to 100% completion to realize there is about 5% of markers never used."

I've played GTA V PC with a trainer and I know how you can play cutscenes and alter the game world and there's a thriving community of modders and online 'hackers' that are running their own scripts and working in RAGE itself to mess with the game. Would it be possible to take all the scripts of the base SP game, add in one of these console output statements to output whether the function has run or not, recompile it (de-decompile), and then play the game to 100% completion? We could see all the functions in the scripts that are being called to identify the ones that aren't. Using the same technique, we might even be able to add output commands for the variables we don't know either, and see how they change over time. If we can decompile the game, can we not recompile it with these 'innocuous' commands in to give us a really in depth look at how the game works? This would swiftly identify all of the functions that are possibly related to the mystery, if it's even possible.

Does anyone know if this might be possible, even on a small scale? The trainer is capable of writing to the screen and a log file when it runs commands, so perhaps we can do the same with the game. If someone has a primer on GTA V and RAGE programming and scripting I'd be happy to start working this. If you can make something that would do just this, I would happily run it and play the game over again to see what results could come from it and would be able to help analyze that data.

How does RAGE and GTA V work in regards to this sort of debugging?
