Does anybodies Career Overview on Rockstar Social look like this?

https://i.imgur.com/9XS4Hk5.jpg

I am referring to the keys and also note that the green and black wings patch in the bottom right has an associated circled question mark too. My save file is 100%, with only the last 3 hunting photographer challenges left to do. I'm all gold medals for all missions and strangers & freaks, as well as all gold for shooting range and flight school for all characters, yet these don't appear "naturally" on my career overview.

I found these by exploring the website code via Firefox's 'Inspect Element' tool. If you think of the keys and their q marks as placeholders for info, well I'm able to make the placeholders appear but can't make the associated stats appear because that is done server-side and relies upon you having done the associated tasks in your save file. For example, if you have a character that hasn't done any safehouse activities or hasn't used a melee weapon you will notice that a question mark hasn't appeared yet for that particular stat. For example this my overview for Frank...

https://i.imgur.com/L4N4mxK.jpg

You can see I have used a melee weapon, so there is a q mark, but no safehouse activity so no q mark for that. Compare that to my Mike overview as it naturally appears...

https://i.imgur.com/RX3wMHj.jpg

You'll see an associated q mark for my safehouse activity but none for my melee as I haven't used one with Mike. I bring this up to show that things don't appear on your career overview until you have done the associated task in game.

These keys are there (potentially) for all 3 protags. To prove these are indeed legit here are some links...

http://cdn.sc.rockstargames.com/images/games/GTAV/career/overview/tables/michael2.jpg

Those are the background images that load with a "no-vehicles" variable active (not really a variable as such, but it's the best way to explain it to people who don't know web coding). Compare that to the background images that load with the "no-vehicles" variable absent i.e. you have the "vehicles" on your game save, whatever that means.

The keys refer to 'boat', 'car', and 'bike' from left to right. The green and black wings patch refers to 'plane'. This is evidenced by the image names above. That is all the info I have on these at the moment. There may well be a simple explanation for this stuff, if so please help me make sense of it because it's driving me nuts as to what they mean and what stats they represent. Anyone with web coding knowledge can verify this for themselves using 'Inspect Element', and they will also see that this stuff doesn't appear to be redundant code. If it is it is the only (and I mean ONLY) redundant code on the page, and in web coding redundant code is usually deleted/blocked out unlike the redundant code left on game discs (i.e hot coffee). This code isn't blocked out, it is seemingly there waiting on you to do the associated in-game tasks.

I also found heaps of in-game icons in the code. By that I mean the icons that appear on the map for activities like the "T" for trev missions or the "M" for mike missions or the icon for the shooting range or the hospital or the cop shop etc. You name it and it's in there whether they be single player icons or online icons.
