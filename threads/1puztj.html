The egg represents the hatches

▲ 2 ptsu/gerstecNov 4, 201319 comments at captureOpen original on Reddit ↗
Documented under:Morse Code Analysis ?

Hey everyone!
So I apologize if this has been posted before I didn't see it when I searched but I have been think about this for a few days.

So here are my thoughts. As of right now there isn't much anyone has found out about the mural. What we do know is that the first of the three boxes (from left to right) represents the various ufo's that appear throughout the map. I believe the second (or middle) box represents the hatches which are found in the ocean.

The egg has a crack on it. Many people thought this meant to discover easter eggs or an egg in general and there's some other ideas.

I think it would have been difficult to represent the hatches thru a picture so to do so they used and egg that is hatching. I haven't found the hatches personally but I have seen videos and when one gets close to the hatch there is some type of morse/ tap code coming from it. I saw a forum where people tried to decode the sound. One even said that they have successfully decoded it and they said it was someone saying along the lines of "hey let's go bowling". It seems ridiculous tho. I believe that if the egg does represent the hatch then the tap/Morse code is the next step and must be decoded properly for the next clue.

If this theory is correct then the first two boxes represent a physical object in the game and the third must too. I don't know if it's a jet pack but whatever it represents does exist and can be found. What do you think?

tldr: the box with the cracked egg is the egg "hatching" and represents the hatches found in the ocean. If so then the boxes represent physical objects found in game and the final box can be found.
