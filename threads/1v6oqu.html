This is the game file discovery: http://gtaforums.com/topic/656269-game-file-mystery-hunt/?p=1064517904

It's a list of about 190 locations in-game what are probably changed during the course of the game.

Example:

New game: https://lh6.googleusercontent.com/-phjtO37qsG8/UshQ6WS5nMI/AAAAAAAADww/ZtlrF7AdCVk/w1149-h850-no/IMG_20140104_181947.jpg

100%: https://lh3.googleusercontent.com/-tMYY4gjYNSA/UshUfjOXF-I/AAAAAAAADx0/OAnBPuUOg58/w1149-h850-no/IMG_20140104_182613.jpg

This example is one of the 190. These changes in the game world are hints that can help us understand the mystery better - why the hell does this change??

This is some background on where this list comes from: http://gtaforums.com/topic/656269-game-file-mystery-hunt/?p=1064506747

This is my plea for a volunteer to lead this in-game search expedition:

Ok guys, time to step up. We need a volunteer to lead this venture. It should probably be someone involved in the decoding thread.

You don't need to know anything technical about the game files to do this, and you don't need a copy of the game files. All you need is a copy of the game and some free time.

This person should create the google doc and recruit a few people to help with the tests. Each location should be plotted with Glokons map and visited in-game. At least once with a new game save, and once with a 100% completion save. If a difference is found between the two, please take a screenshot.

Subtle changes in the game (like the billboard example tgas pulled to start your appetite - it was already posted about here) are important clues to solving this mystery. We now have a reliable method of looking for them.

Volunteer?

And this is where you can best get in touch with the game file team: http://gtaforums.com/topic/656269-game-file-mystery-hunt/?p=1064518115
