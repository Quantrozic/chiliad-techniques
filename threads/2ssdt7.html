I know this post will get backlash, so I'm just going to say that for the record, I'm only one guy, my opinion isn't going to change everyone's view, nor should it.

It seems to me that R* have hidden this with a great deal of deliberacy. Nobody's accidentally found the Jetpack yet, and why? Because the solution doesn't allow for accidents. Now, I honestly think this means that standing and testing something that could be relevant is pointless until we have all the stepping stones to link it definitively. For example, for those trying to open the bunker doors, whilst I commend your efforts, don't you think that any conventional method would be too simple? Bombs, tazers, it's all too easy. Someone would have found it by accident. But R* don't want us to do that. I think we need to do things in a very, very specific order, and until then we will learn nothing new, because the game requires all the criteria to be met. Now, the crux of my point is this; instead of randomly coming up with hundreds of hypotheses, let's instead search for the tangible, physical clues we're obviously missing. R* wouldn't want us to find the answer by essentially guessing. So we won't. Simple as that.
