Hi all,

Been combing over the script files some more and decided to check out am_armybase, since it obviously is tied to the fort. Interesting enough, I see that there are some coordinates entered at the beginning of the script, along with what appears to be a conditional check if the player is close to them, which then sets off the player wanted level:

if ((num8 | sub_38E(rPtrOfs(_s, 0), rPtrOfs(_s, 4), rPtrOfs(_s, 8), 0)) != 0)
{
    if (PLAYER::GET_PLAYER_WANTED_LEVEL(PLAYER::PLAYER_ID()) < 4)
    {
            PLAYER::REPORT_CRIME(PLAYER::PLAYER_ID(), 36, PLAYER::GET_WANTED_LEVEL_THRESHOLD(4) - PLAYER::GET_WANTED_LEVEL_THRESHOLD(PLAYER::GET_PLAYER_WANTED_LEVEL(PLAYER::PLAYER_ID())));
     }
     else
     {
            PLAYER::0xD15C4B1C(PLAYER::PLAYER_ID());
     }
 }

At the very bottom, it looks to check to see if the player (or some object) is within an "Angled Area" of 13 of those structures, which I imagine is some sort of visibility check.

Also interestingly enough, the points come in pairs, where the first object seems to be at base level (a Z value of 29-31) yet the second object seems to be in the sky. Here are some examples:

setStruct(-2807.397f, 3264.226f, 29.92764f, 3, getElemPtr(6, &num3, 12));
setStruct(-2879.805f, 3309.01f, (37.57864f) + itof(A_3), 3, getElemPtr(6, &num49, 12));

setStruct(-2808.236f, 3264.634f, 29.92764f, 3, getElemPtr(7, &num3, 12));
setStruct(-2747.55f, 3187.8f, (37.45682f) + itof(A_3), 3, getElemPtr(7, &num49, 12));

The first two parameters are the x and y values of the object and the third parameter is the z position. You can see that these objects have a starting Z position of around 37, but another value is added, which at this point I haven't yet deconstructed. So I wonder if the first object of the pair is a camera / soldier, and the second object is that objects "eye", meaning the object that does the check to see if the player (or some other object) is in range.

If you have a look at these points, does anything stand out to you guys? Are these camera locations? Or soldiers? If so, do we have to take them out so the conditional range check progresses to unlock something?

Just thought I would throw this your way.

Edit: One of the reasons I am interesting in this is that it seems that instead of covering an entire range, they have points which watch for the player to give a 4 star wanted level. That means, theoretically, that we should be able to find weak spots. In looking at today's posts about the Maze Bank being an egg, it get's me thinking: Do we have to solve a maze somewhere? Maybe there is a maze in the fort...meaning a certain path that you need to traverse which DOESN'T trigger the wanted level. If we look back to GTA: San Andreas, you really had to go through hoops of not being detected, as well as pave through a maze like path, just to unlock the jetpack, so maybe the same applies to this game.
