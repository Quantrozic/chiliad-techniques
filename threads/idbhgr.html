I was looking around the scripts to see if/when the JetSteal sequence might take place (no evidence yet that it does) and decided to catalogue which scripts call which ymaps for easier referencing later. A scripted ymap is a change to the map/world that can be toggled on/off within the scripts

This link lists all (I think) the scripted ymaps in JSON format referenced by number, shows the coords, which scripts you can find it referenced in, and any strings (words/names) associated with it.

This link is organized by scripts (also JSON) so you can look up specific scripts/missions to find which ymaps are referenced in them.

This link has the section of code that's used to call the scripted ymaps and a link to the version of decompiled scripts I've been using if you want to follow along. Basically each ymap is given a number 1-200 and is called to be turned on/off by referencing that number. I've also listed at the top which ymaps I couldn't find any reference to, and which ymaps I could only find referenced in mission_repeat_controller. It shouldn't be too hard to figure out what mission is referenced in mission_repeat. Their must be another way (probably through flow_controller but I haven't looked too hard yet) to call the scripted ymaps if so many only have a reference in mission_repeat_controller but seem to be also triggered through normal gameplay. The general flow is firstFunction has a call to secondFunction which has a call to thirdFunction which holds the references to ymaps. By searching for thirdFunction (the string "jetsteal" is handy because it's only found in thirdFunction) you can work backwards and find all parameters it's called with. If you find out how else they get called please let me know. Sometimes mystery related stuff is called just slightly differently in the scripts, possibly to prevent quick bruteforce searching/solving.

These are the scripts where it wasn't immediately obvious which scripted ymap was being called and the func# responsible for calling the ymaps.
