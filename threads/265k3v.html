This is a small patch to test a few things.
Underwater lighting and wildlife.

This download is for the BLES version of the game (European), if anybody on BLUS (United States) wants a try please pm the common.rpf from your game

There is a value for the water color, it was a semi transparent blue, and I believe it controls the tint of the water.
I have changed this value to completely transparent, in hopes that we may be able to see a little clearer while exploring.

I would suggest getting near the sub, wait for a clear sunny spell and make a save. Head out to a part of the ocean and take a deep look around, maybe screenshots if you can.
Then apply the patch, reload your save and go to the same part of the ocean and do a comparison.
See if the direction I'm travelling is even worth it.

Also in this patch, I changed the attitudes of Sharks and all other wildlife (except cougars).
Sharks were originally set to hate the player, and disregard everybody else. I changed them to hate everything in the game. I'm not even sure that NPC's encounter sharks anyways.
All the other wildlife was set to hate the player, I changed that so they are now tame.
I have tested this and it works, you can run right up to deer and they don't acknowledge your existence.
Maybe it will help if you are having trouble with the hunting challenges.

Download:
https://dl.dropboxusercontent.com/u/43058382/common.rpf

This is the common.rpf file that belongs in USRDIR

Open your game folder (external or internal) and enter the USRDIR directory
rename the existing common.rpf to common.rpf.bak
Then, copy over the common.rpf from the download.
Boot game

If you want to switch back to stock, delete the patched common.rpf, then rename the common.rpf.bak to common.rpf

Saving with this patch installed should be harmless, but I'm not responsible if you bork your save.
So, backup your save data beforehand if you plan on going this route.
