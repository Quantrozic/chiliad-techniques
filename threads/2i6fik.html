Morse code sound near radio tower.

Documented under:DTMF and Morse Tone DecodingMorse Code AnalysisPitch-Contour Morse Extraction

I've been following the mystery since last October and trying to observe in game oddities whenever possible. First time poster, long time lurker. I don't remember anyone ever mentioning a Morse code sound. I hear it next to the rebel radio tower near Bolingbroke penitentiary. I just ran into it screwing around. Game time is 4:38 am. I walked away like ten feet at 4:48 am and the sound stopped. I started to type this post and I heard a few more intermittent bleeps of Morse code at about 6 am. The moon was fogged out. Does anyone here understand Morse code? I'm going to search for a Morse code translation app to see if I can decipher the message. If this has already been found please downvote this post to oblivion. I have a 100% save game but I'm playing on a newer 27% completed game. Please tell me I'm not crazy and that someone has heard this. Or if you haven't go check it out for yourself, I'm going to keep investigating and will update if I find anything of interest. Update: Originally I found this using Trevor. I tried on my 100% save file using Franklin and the more and the Morse code noises keep happening, but only in one hour blocks from 2:50am to 3:50am and then again from 4:50am to 5:50am. Also it seems there are no Morse code audio translators available for my windows phone. Only text to Morse code. Kifflom
