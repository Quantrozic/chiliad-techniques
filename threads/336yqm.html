I see many posts about textures about bits of code from the game meaning they are both somewhat accessible as of now. As each texture or model in the game has a name, it must be referenced in the code by that name (hashed or not).

What I'm thinking is that some of these textures, whether the UFO symbols or mural on Mount Chiliad, the sun paintings or the rock model at the Altruist camp or anything else related to the mystery could be triggers. If they are, that triggering code would reference them by name.

Even something as simple as the texture used for the doors next to the mural. If that door opens, those door models and textures will be referenced in the code that opens them. And if such code is found, it can hold other clues.

Just an idea for people who are knowledgeable enough to give such a thing a try. Is there even any way, as of now, to search through the game's code files for such references?
