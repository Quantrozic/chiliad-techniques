Locating props in the world

▲ 14 ptsu/Trevor_EMar 5, 201543 comments at captureOpen original on Reddit ↗
Documented under:Spatial Autocorrelation Testing of Prop Placement

The point of this thread is trying to see if props are able to be located properly in files, especially cutscenes. The current train of thought ive seen is that if we cant find the location for a prop(egg, asteroid, etc) it must not exist. I am currently having issues even linking obvious props that are used everywhere to their location on the map. If we cannot locate known props I have to say our method for locating unknown ones is pretty flawed.

I have also matched more locations then I have seen mentioned before so I am not sure everyone is testing with a full file pack. The PC release will greatly help with this.

This being said, I have located the below objects. I would like to see if we can play "I Spy" and try to find these objects in the world. They are in cutscene files, and I believe can either be in a cutscene or can spawn directly after one. The most obvious case of this is the textures from the UFO michael gets abducted in. If we can find the known props using this method, the alien egg should be somewhere similar. If they are just false matches I dont believe it should be discouraging until we find a way to locate props more accurately.

All of these locations sound at least sane though, so I have hope. For the record, between the runes/eggs/asteroid/different color lasers/space_shooter references in files, I firmly believe the level either exists or was planned to exist and got cut. I have not seen enough proof yet that it has been cut though so here we are.
