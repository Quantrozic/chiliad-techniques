The idea: purple seems to scream Maze Bank + rotation + observation (maze + rotate arrows + eye), plus a few possible “conditions” (brain / lightning / waves).

If anyone’s willing, here’s a friendly test you can run on console in Story Mode.

Quick version (what to do)

Mode: Story Mode
Character: Michael
Location: Maze Bank roof (heli up)

Action: Use a scoped weapon (sniper if you have it). Slowly pan/rotate and “observe” a few skyline targets in a fixed order.

Hold each target in the scope for ~10 seconds.

Suggested clockwise target sweep

(These are based on an old mapping idea from the sub — if you disagree with a target, totally fine, just note what you used.)

  1. Del Perro Pier Ferris Wheel (starburst)
  2. Something “psych/therapy” themed for the yin-yang (Friedlander angle, or suggest a better match)
  3. Weazel Plaza (keyhole)
  4. Augury Insurance building (stacked “cake” icon)
  5. FIB/IAA buildings (scales)
  6. Legion Square stairs sculpture (stairs)
  7. Vanilla Unicorn (the “two circles/venn” style icon mapping)

Optional: try one “condition” at a time (separate attempts)

If you’ve got time, it’d be amazing to try variations (one at a time):

  • Baseline: no special ability, clear-ish weather
  • Brain: run the same sweep with Michael’s special ability ON
  • Lightning: run it during a thunderstorm
  • Waves: run it with radio ON (pick one station, don’t change it mid-run)

What to watch for (anything unusual)

Even small stuff is useful:

  • a unique audio cue
  • screen/filter change
  • weather shift
  • a text/email/phone event
  • a weird spawn near Maze Bank or at a target

If nothing happens, that’s still valuable data — it helps us rule it out cleanly.
