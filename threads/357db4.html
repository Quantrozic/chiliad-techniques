Looking at the code that was posted, my guess is that g_19456 is a variable that holds the index (position) of something in an array with 1000 elements. My reason for guessing 1000 is that 999 is the 1000th element in an array, and the number 1000 is significant because Chiliad means "a group of 1000".

An array is sort of like a list, if you imagine a grocery list, the very first item on the list would be at position 0, and the last would be the number of items on the list minus one, so if you had a list that had 1000 items on it, the very last item would be at position 999.

So that leaves the question 'what is the -1 for?'

When you're using an array in programming and keeping track of the position of an item in that array, usually you will default the position to -1, since -1 (or any negative number) is an invalid number, since valid indexes start at 0 and end at the number of elements minus one (again, 999 if you have an array with a size of 1000)

Sooo.. my guess is that g_19456 is a variable holding the index of an item in some important array the game is using. I honestly have no idea what it might be
