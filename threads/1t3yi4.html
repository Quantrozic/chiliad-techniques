Convert Snapmatic photo links to images (Retain Location Data)

▲ 24 ptsu/GlokonDec 17, 201315 comments at captureOpen original on Reddit ↗
Documented under:Snapmatic Photography & Location-Data Cataloguing

Hey guys, just releasing another tool here for anyone interested, it converts the Snapmatic photo link to one where you don't have to log in, I heard a lot of people complaining about that.

It also retains the location data exactly as taken from the Rockstar servers.

Snapmatic Converter

Just enter the Share URL from the rockstar website, and it will generate a link for you to share where you don't have to login.

Example: http://gta5snapmatic.glokon.org/s/0705/UP5tUReheUGVhQjtAS2Wxw/Mount-Chiliad/398.16/5719.88/

EDIT:

-- API --

Here is the API: http://gta5snapmatic.glokon.org/api.php?url=

If you put the rockstar URL after that it will return JSON, if the URL is correct it will return _OK if there is an error it will return with status _ERROR.

The API will return 5 pieces of data:

  • status - This is the status of the request, _OK is good, _ERROR is bad.
  • x and y - These are the coordinates returned.
  • name - This is the name Rockstar puts on every image, each are generated on a per location basis.
  • url - This is the URL to the image.
  • g-url - This is the URL to my site that contains the location data and everything
  • g-url-short - This is the TinyURL that is retrieved from generating a smaller url using g-url.

For example: http://gta5snapmatic.glokon.org/api.php?url=http://socialclub.rockstargames.com/member/next1x/games/gtav/snapmatic/mostrecent/photo/LTNEqP13cECtu4bKxcgtSg
