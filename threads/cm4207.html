Analysts of GTAV “Karma”

In most situations where a game says it features “Karma” (like RDR2 or in the past Fable) the game will track good and bad choices to cause an effect on the player. Through what we know and use of the “Karma Compass” that gives us clues for order of missions we then know this is not the case in GTAV.

It’s most likely the steps for the GTAV Mystery are set in stone (more or less)and guided through clues. So deductive reasoning tells us “Karma” is only a label (or name) for clues of direction rather then a game mechanic. What this means is you shouldn’t worry about things like “I killed X number of people today, so I must do yoga X amount of times” to balance. That’s because things like kills would most likely be a set total overall and therefore any other stat would be a set number or goal as well. This being true would suggest the player only needs to find these numbers or choices through clues and once matched then that step would then be solved.

So does this mean we should ignore references to “Karma”?
Not at all. You should be looking for “Karma” regularly. Karma would no doubtably be the dotted line or compass of a treasure map leading you to its end.
https://i.imgur.com/Xc6DXHt.png
This is because references to Karma (direction, symbols, colors, so on)is what gives you these set numbers, choices or order. Ergo a set of answers to the mystery.
