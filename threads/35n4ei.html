"Please note that recordings made at this time won't allow for camera changes in the Rockstar Editor"

▲ 17 ptsu/Tezla55May 11, 201515 comments at captureOpen original on Reddit ↗
Documented under:Replay-Buffer Anomaly CaptureRockstar Editor Time-Lapse Capture

I was playing with the Angry Planes mod earlier while driving around the east side of the map as Trevor when I noticed a notification pop up saying "Please note that recordings made at this time won't allow for camera changes in the Rockstar Editor".

I know that this shows up when you enter first person, but I was playing in third person.

I drove off, and then noticed that the message went away. When I drove back, the message came up again, so I assumed that the message only comes up within that certain area. However, when I left and came back again, the message didn't come back up. When this happened, I assumed that what I experienced earlier must have been a glitch.

Then, I changed the time using Scripthook V. I noticed that the message came back but ONLY when the in game clock was at 23:00. Also of note is that it was a full moon when the message came up. I also tried on a day where there was no full moon, but the message doesn't come up. My best guess is that it must be triggering something when these conditions are met, and that is why it blocks the Rockstar Editor.

Has this happened to anyone else before? I have doubts that this has to do with the mystery, but I don't have an explanation as to why else this would happen.
