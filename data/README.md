# Dataset

Machine-readable data behind the Chiliad Techniques Encyclopedia (v1.2.0, built Jul 07, 2026). `techniques.json` holds all 343 technique entries (metadata, case-ID lists, weak-match subsets, human verifications); `threads.csv` holds one row per bundled thread (6286 rows) with its Reddit metadata and the techniques it documents.
