# Dataset

Machine-readable data behind the Chiliad Techniques Encyclopedia (v1.1.2, built Jul 06, 2026). `techniques.json` holds all 298 technique entries (metadata, case-ID lists, weak-match subsets, human verifications); `threads.csv` holds one row per bundled thread (4384 rows) with its Reddit metadata and the techniques it documents.
