Techniques encyclopedia

Dataset

Machine-readable data

The data behind this site, published for reuse: version 1.1.0, built Jul 06, 2026.

Files

  • techniques.json: all 298 technique entries with full metadata, complete case-ID lists, weak-match subsets, and human verifications. Includes a meta block with version, corpus provenance, and license.
  • threads.csv: one row per bundled thread (4,384 rows): id, title, author, UTC timestamp and date, score, comment count at capture, flair, Reddit permalink, the technique IDs it is documented under (|-separated), and which of those are weak matches.

License: CC BY 4.0; attribute "Chiliad Techniques Encyclopedia" with a link back. Pipeline details are on the methodology page. Post IDs are Reddit base-36 IDs, so rows join cleanly against any other r/chiliadmystery dataset.
